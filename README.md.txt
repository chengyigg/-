# CardRPG - 卡牌 RPG 游戏核心系统展示

本项目是我独立开发的卡牌 RPG 游戏的技术作品集，重点展示 **软件架构设计**、**设计模式应用** 和 **代码规范**。

## 🎮 项目简介

- 基于 Godot 4 引擎，使用 C# 开发
- 包含完整的回合制战斗、数据驱动对话、多场景存档等系统
- 独立开发，目前为大二在读

## 🏗 架构亮点

- **组合模式**：卡牌 UI 拆分为外观、交互、动画、模式四个独立组件
- **状态机**：回合制战斗的流程控制
- **数据驱动**：对话系统和卡牌效果通过 Resource 配置，逻辑与数据分离
- **事件驱动**：各系统通过信号解耦，减少硬依赖
- **单例管理器**：全局服务（存档、条件、转场）统一管理

## 📁 目录结构

| 文件夹 | 说明 |
|--------|------|
| `Core/Managers/` | 全局管理器（条件、存档、转场等） |
| `Core/Player/` | 玩家控制器与跟随者系统 |
| `Dialogue/` | 对话播放器、界面与选项执行器 |
| `Battle/CardUI/` | 卡牌 UI 组件系统（外观/交互/动画/模式） |
| `Battle/Managers/` | 战斗管理器、手牌管理器、回合状态机 |
| `UI/StatusBar/` | 状态栏、背包过滤、道具系统 |
| `UI/Settings/` | 设置菜单与音量控制 |
| `UI/KeyRebinding/` | 按键重绑定系统 |
| `UI/SaveSelect/` | 存档选择界面 |
| `Resources/` | 自定义 Resource 数据类 |

## 🚀 关键技术展示

### 卡牌 UI 组件系统
将单个卡牌控件拆分为四个子组件，各司其职，通过信号通信。

### 对话系统
支持打字机效果、选项分支、可改变对话、传送后触发对话、历史回溯。

### 存档系统
保存/加载场景位置、条件状态、卡组、跟随者等多维度游戏状态。

### 按键重绑定
完整的键位配置、保存、冲突检测，支持键盘和鼠标。

## 📝 关于命名

早期原型阶段使用中文标识符以加快开发迭代。核心脚本已逐步重构为英文命名。
